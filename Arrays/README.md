# 📌 Phase 1 – Arrays (20 Problems)

This folder contains solutions to **20 foundational array problems** in Java.  
Each solution is documented with a consistent **Problem → Approach → Complexity** format, focusing on clarity and optimized techniques.

## ⚡ Complexity Highlights

- Most solutions run in **O(n)** or **O(n log n)** time  
- Space optimized to **O(1)** wherever possible using in-place updates
